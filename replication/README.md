# EV battery replacement revision
Run from this directory. The accompanying derived input tables make the numerical accounting independent of a remote repository. The baseline source modules are from https://github.com/Sami6639/EV-Battery-Carbon-Replication at e96c3b8ddae2a80689c3fe8493d75ab92fe251e0. Only the baseline modules used here are required.
1. Install Python, NumPy, pandas, scipy, PyYAML, pyarrow, matplotlib and fastsim==3.0.6. The archived upstream environment is in requirements-lock.txt. The revision was run using Python 3.12 and FASTSim 3.0.6.
2. Create raw/ and download two original files from Luh & Blank (2024), DOI 10.35097/1947, CC BY 4.0. They are cell_eocv2.zip (https://www.radar-service.eu/radar-backend/archives/zYYmSEIWMwoELRCK/retrieveFile/tRlKWnIpaOUgrqEa) and cell_plsv2.zip (https://www.radar-service.eu/radar-backend/archives/zYYmSEIWMwoELRCK/retrieveFile/uEtROzxMiabpTrYb). Store each under its original filename. audit.py verifies SHA-256 before opening either file.
3. Run python revision/audit.py, then python revision/extensions.py, python revision/figures.py then python revision/technical.py and finally python revision/cell_weighting.py. Independent runs can use separate extracted directories. Results overwrite the included baseline copies.
4. Check the CSVs against the manuscript and the point-by-point response. Positive carbon contrasts mean that immediate full replacement emits more than the comparison policy. Rows summarize controlled scenarios or repeated check-ups, not population weights.
## Files and units
pairs: same-cell nearest check within 24 hours, one-to-one, q = available capacity relative to initial, r10 and r1s in relative units. bands: number of checks, cells and experimental conditions. fastsim: two fresh cycle simulations and weighted results. original_savings: exact stepwise 2025 reconstruction. service and routes: counts of paired checks failing a specified duty. delay: operating and manufacture-only decomposition for age eight in 2025. power: nominal-open-circuit-voltage fixed-power sensitivity. endpoint: next observed resistance relative to original ceiling. circular: matched service expansion at old and replacement pack exit. allocation: throughput-based mobility accounting. repair: conditional intervention comparison before allocation, requiring tested whole-pack service recovery.
## Provenance
Luh and Blank (2024), DOI 10.35097/1947, are the source of the matched laboratory measurements. Archived vehicle traces are derived FASTSim results. The ID.3 benchmark uses Wassiliadis et al., DOI 10.14459/2022mp1656314. The conditional automotive stress case uses Schreiber et al., DOI 10.14459/2024mp1755598. Derived electricity inputs are from Cambium 2024, DOI 10.7799/2560791. Charging measurements are from Sevdari et al., DOI 10.1016/j.seta.2023.103512. Pack factors for the NMC811 and LFP scenarios follow Llamas-Orozco et al., DOI 10.1093/pnasnexus/pgad361. Survival is the source project's bounded implementation of Greene and Leard, DOI 10.1016/j.tra.2024.103982. Vehicle pack energy and wall-energy reference are from the 2024 NREL Transportation Annual Technology Baseline. Mileage and route benchmarks are from 2022 NextGen NHTS v2.1. The circularity section distinguishes input assumptions from measurements.

## Final technical checks
Run technical.py to create the final Figure 2. The duty_curve table gives capacity-only and joint classifications over the range of route lengths; survey_position locates benchmarks in two separate distance distributions. The NHTS input CSVs aggregate positive survey weights by valid recorded distance. early_replacement separates production changes, vehicle withdrawal and operating losses under an annual compulsory-intervention probability. storage_thresholds gives continuous roots across compatible storage scenarios; blank roots indicate no break-even on [0,1]. id3_boundary contrasts terminal energy with assumed stored-energy loss adjustments. ceiling_transitions records the four current/next exceedance combinations for each capacity band.

The final cell_weighting.py step creates Figure 3 and cell_weighting.csv. The CSV reports check-weighted and equally cell-weighted failure fractions at 201.1744 and 400 km for each central consumption reference. Panel B holds the 2035 one-year MidCase crossing scenario fixed.

Run python revision/storage_resistance.py after technical.py to generate storage_resistance.csv for the installed-pack resistance sensitivity.
